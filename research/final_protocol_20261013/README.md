# Source-only RIME experiment adapters

The four core cells share exact numerical atom deduplication, source-fitted scales, patient context, head capacity, data splits and optimization budgets. Attention and kernel-measure pooling are crossed with Moment and signed Laplace readouts. Original raw-attention comparisons remain separate. Scorer controls include geometry-only, local linear, exactly capacity-matched local MLP and scorer-only shuffled context. A 56-dimensional weighted LogSumExp and diversity-regularized attention provide alternative controls.

Native site-value supervision is admitted only after source-side patient-conditioning checks. Recipient-excluded RIME reference models recompute native patient context, conditional scores, weights and aggregation after site deletion. True site-value supervision is compared with two source-only shuffles, ordinary patient-level auxiliary supervision and no auxiliary learning. Site targets do not identify individual-frame value or clinical causality. All source gates precede new auxiliary outer predictions.

These adapters require caller-owned Stage196/Stage197 inputs, cached frozen JEV features, `CONFIG.json`, `INPUT_LOCK.json`, and a dependency-hash manifest. Copy the adapter directory under the corresponding experiment root and provide those private manifests before running `controller.py`. Core training requires all five outer centres and source-only inner selection; the executable queue has a fixed deadline and preserves the original campaign. The server-specific reference-index correction is isolated in `anchor_adapter.py`.

The portable implementation lives in `src/if_redesign/rime`; `ScoreControl` and `train_control` expose the scorer and auxiliary controls. The adapter's bundled implementation preserves the exact frozen dependency versions. Run portable synthetic checks with `pytest tests/test_rime*.py`; private execution prechecks require the original caller-owned dependency tree. This source tree contains no patient data, fitted weights, clinical results or manuscript. Clinical contributions remain subject to the actual ablations and admission gates.

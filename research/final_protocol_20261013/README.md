# Private-data experiment adapters

These adapters implement the locked four-cell source-CV workflow, selector warmup, conditional/local capacity controls, and source-gated native site-value supervision. They require caller-owned private Stage196/Stage197 inputs, cached frozen JEV features and manifests. This source tree contains no patient data, fitted weights, clinical results or manuscript. Synthetic execution tests are not patient evaluation. No autonomous upload is performed.

# 宫颈多模态临床认知对齐：预注册式实验方案

## 研究边界

本实验借鉴 Zheng 等人的 CogAlign 框架（分层认知 SFT、病灶擦除反事实、格式/认知/诊断组合奖励），但把胃肠镜的层级重写为宫颈任务：临床先验 → 阴道镜宏观形态 → OCT 微结构 → 跨模态整合 → CIN2+ 判断。它是方法迁移试验，不是原论文官方代码复现，也不把原论文在胃肠数据上的结论直接外推到宫颈数据。

- 参考论文：https://arxiv.org/abs/2603.20698v3
- 基座模型：https://huggingface.co/Qwen/Qwen3-VL-2B-Instruct
- 训练框架：https://github.com/modelscope/ms-swift

截至本实验初始化时，论文页面未给出可直接运行的官方 CogAlign 仓库，因此本目录实现的是依据论文方法描述构建的独立适配版。

## 临床问题和主要假设

问题：在年龄、HPV、TCT、阴道镜序列与位点级 OCT 序列可用时，强制模型按临床证据层级整合，是否能比相同 Qwen3-VL 基座的诊断式 SFT 更准确、更可解析，并对真正病灶区域的擦除比对随机同面积区域的擦除更敏感？

主要假设（Formal v1a，已启动）：`分层 SFT` 相对等预算的 `诊断式 SFT` 提高外部中心 CIN2+ 的宏平均 AUPRC；配对患者聚类 bootstrap 95% 区间的下界需大于 0，才支持主要效果。

Formal v1b 的主要假设为：在 v1a 主方法上增加经复核 ROI 的反事实 GRPO 后，宏平均 AUPRC 进一步提高。v1b 仍受 ROI 准入门控，不与已启动的 v1a 混称为已完成实验。

关键次要假设：

1. 分层 SFT 提高严格格式通过率和证据字段完整率。
2. 病灶 ROI 模糊后的 CIN2+ 概率下降量大于随机同面积模糊。
3. 收益在医院中心和缺失模态分层中不只由单一中心驱动。

## 分阶段执行

### Pilot v0（当前）

- 104 例：train 64、validation 20、test 20；每个划分阳性/阴性各半。
- 仅选择阴道镜与本地 OCT 文件同时存在的病例。
- 为避免同一患者重复阴道镜带来的乐观偏差，每位患者稳定哈希选一个检查位点。
- 阴道镜最多 4 帧、OCT 最多 6 帧，以无标签规则均匀抽帧并做拼图。
- 目的仅为验证数据通路、格式学习和初步方向，不估计真实患病率下的临床性能。

### Formal v1a（分层 SFT，已启动）

- 分析单位为检查位点/`case_id`；由于同一患者可能有多个 OCT 位点且标签可不同，置信区间按 `patient_id` 聚类。
- 患者及完全相同图像证据不得跨训练、验证和测试。
- 使用逐中心留一（LOCO）评估，并报告每个中心结果；阈值、早停和校准只用源中心开发集。
- 保留自然患病率，不做测试集平衡抽样。

### Formal v1b（反事实 GRPO，ROI 复核后）

- 沿用 v1a 的患者与中心划分，不重新抽取更有利的测试集。
- 仅用训练中心的经临床复核 ROI 构建病灶擦除和随机同面积擦除样本。
- 与 v1a 的完整分层 SFT 做等数据、等基座的增量比较。

## 比较模型

1. Clinical-only：年龄、规范化 HPV、规范化 TCT。
2. Qwen3-VL zero-shot：相同结构化输出提示，不训练。
3. Diagnosis-only SFT：相同标签与训练预算，不提供层级观察目标。
4. Hierarchical SFT：标签盲图像观察草稿经质控后，加训练标签组成分层目标。
5. 冻结多模态特征的线性分类器作为旧图像表征参照；其结果不混入新模型选择。

待 v1b 解锁后另加入 Hierarchical SFT + GRPO：格式、认知关键词、诊断奖励权重为 1:1:2，KL `beta=0.04`。

## 反事实的准入条件

项目内没有现成病灶 mask、polygon 或 bbox。自动/中心 ROI 只能用于代码冒烟，不能支撑病灶因果主张。进入正式 GRPO 前，每个 ROI 必须：

- 标明原始图像、归一化坐标、标注者和版本；
- 至少一次临床复核；
- 同时生成病灶模糊和随机同面积模糊；
- 保留原图，记录变换参数；
- 先验证“病灶模糊的风险下降 > 随机模糊”。

把擦除图直接赋为阴性是强假设。脚本默认不赋新标签，只有显式传入 `--assign-negative` 且 ROI 已复核时才允许生成论文式 GRPO 样本。

## 指标和失败标准

主要指标为 AUPRC；另报告 AUROC、灵敏度、特异度、F1、Brier、ECE、格式通过率、证据字段完整率及患者聚类 95% bootstrap 区间。

任一条件出现时，不得声称方法有效：

- 测试/外部中心参与提示、目标生成、阈值选择或 checkpoint 选择；
- 伪报告/标签模板进入图像观察草稿；
- 同患者或完全相同图像跨划分；
- 未复核 ROI 被当作病灶真值；
- 主比较区间跨 0，或提升仅由单中心产生；
- 解析覆盖率低于 95%。

## 复现配置

- Qwen3-VL-2B-Instruct，官方权重 commit `89644892e4d85e24eaac8bacfd4f463576704203`。
- Pilot SFT：LoRA rank 16、alpha 32、学习率 `1e-4`、cosine、3 epochs，冻结视觉编码器和对齐器。
- Formal v1a 延续相同 3-epoch 配置，单卡 batch 4、梯度累积 2；关键优化器/LoRA 设置仿照论文，但不冒充论文八卡 global batch 128、400 steps 的等算力复现。
- Pilot GRPO：学习率 `1e-6`、`beta=0.04`、4 generations、50 steps。正式复现实验扩为论文的 8 generations，并在显存允许时使用预注册训练步数。
- 随机种子：20260902。
